## 🎉 你好，欢迎光临！

这是我的个人博客，很高兴在这里遇见你。

### 关于我

我是一名大学生，从接触编程开始就迷上了用代码创造东西的感觉。从最初的 HTML 页面，到 Python 小工具，再到现在的各种项目折腾，编程已经成为了我生活中不可或缺的一部分。

### 为什么搭建这个博客？

1. **记录学习** — 把学过的知识系统化整理，加深理解
2. **分享经验** — 希望能帮助到和我一样在编程路上摸索的人
3. **督促自己** — 保持持续学习的习惯

### 我会写些什么？

- 🐍 Python / Java 学习笔记
- 🌐 前端开发经验
- 🤖 算法与数据结构
- 📝 项目开发过程
- 💭 日常随笔

### 技术栈

这个博客使用 **Hexo** + **Butterfly 主题** 搭建，部署在 GitHub Pages 上，支持暗色模式、站内搜索、代码高亮等特性。
