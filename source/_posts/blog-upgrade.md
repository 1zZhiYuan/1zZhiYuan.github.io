经过一段时间的折腾，我的博客迎来了全面升级！这次换上了 **Hexo Butterfly 主题**，功能和颜值都上了一个台阶。

## ✨ 新特性一览

### 1. 暗色模式 🌙

现在博客支持自动跟随系统切换暗色模式，你也可以手动点击右下角的月亮图标切换。深夜写代码看博客不再刺眼。

### 2. 站内搜索 🔍

在导航栏点击搜索图标，输入关键词即可快速查找文章，支持全文搜索，方便快捷。

### 3. 代码高亮 💻

代码块支持语言标识、行号显示、一键复制，并且有 Mac 风格的高亮主题，阅读代码体验更舒适。

### 4. 文章目录 📑

文章右侧会自动生成层级目录，点击即可跳转到对应章节，长文阅读导航更方便。

### 5. 图片查看 🖼️

点击文章中的图片可以放大查看，支持画廊模式浏览。

### 6. 评论系统 💬

基于 GitHub Discussions 的评论系统，无需注册即可发表评论（使用 GitHub 账号登录）。

### 7. 更多特效 🎨

- 鼠标点击爱心效果 ❤️
- 背景粒子动画
- 页面加载动画
- 打字机副标题效果
- 页面滚动进度条

## ⚙️ 配置要点

```yaml
# 暗色模式
darkmode:
  enable: true
  autoChangeMode: 1  # 跟随系统

# 搜索
local_search:
  enable: true
  preload: true

# 粒子背景
canvas_nest:
  enable: true
  color: '0,100,255'
```

Butterfly 主题的配置非常灵活，几乎所有元素都可以自定义。如果你也在用 Hexo，强烈推荐试试这个主题。
