## 项目简介

**NoteBase** 是我开发的 Windows 本地笔记应用，用 Python + PyQt5 构建，当前版本 **2.0.0**，已用 PyInstaller 打包为免安装的 `NoteBase.exe`——双击就能跑，不需要装 Python 环境。

它解决的需求很简单：写点东西的地方。技术文档、日记、小说草稿、待办清单，都存在本地 JSON 文件里，**全程零联网**。这个项目和聆记 AI 是同一条思路：数据在你手里，隐私不靠承诺。

## 功能全景

**编辑器是双模式的**——富文本模式适合快速记录，纯文本/代码模式支持 12 种语言的语法高亮（基于 Pygments），写代码片段和 Markdown 也不憋屈。

围绕「整理和找回」，它做了：

- **分类 + 标签**两级组织，多级分类自由搭建结构；
- **全文搜索**：标题、内容、标签都可搜，带搜索历史和自动补全；
- **回收站**：删除的笔记可恢复，支持自动清理；
- **自动保存**：定时保存，手滑不丢稿。

围绕「长期写作」，它做了：

- **写作统计**：字数统计、写作时长、每日目标追踪；
- **日记模式**：天气、心情记录专用界面；
- **小说模式**：专注写作界面，带字数目标；
- **代码片段库**：常用代码块收藏，内置 Git 命令速查。

**导出**支持 Markdown / TXT / PDF 三种格式，笔记随时带走。

## 隐私与存储：零联网设计

NoteBase 没有网络模块，也不申请任何网络访问：

- 所有笔记存在本地 JSON 文件中，数据结构透明，随时可以自己备份迁移；
- 不注册、不登录、不同步，启动即用；
- 打包后的 exe 不携带任何遥测。

这也是我把「完全本地」写进副标题的原因：这款应用的全部卖点，就是它对你的数据**不感兴趣**。

## 敏感笔记：AES-256-GCM 加密

有些笔记不希望被别人直接看到（密码备忘、私人日记），所以实现了笔记级加密：

- 算法选择 **AES-256-GCM**——除了加密，GCM 模式自带完整性校验，内容被篡改过会直接解密失败，而不是给你一份被改过的「明文」；
- 实现基于 `pycryptodome`，密码经密钥派生后使用，加密在笔记保存时完成；
- 操作方式很轻：列表里右键笔记 → 加密/解密，输一次密码即可。

加密是**可选的、按笔记粒度**的：大多数笔记保持明文（搜索和统计才不受伤），敏感的几篇单独上锁。

## 工程与打包

- 技术栈：Python 3 + PyQt5 + Pygments（代码高亮）+ Markdown 渲染 + pycryptodome（加密）；
- 打包：PyInstaller 分别产出单文件版和目录版，两份构建都做了启动速度和体积权衡；
- 维护：自带使用说明书（14 个章节，从快速入门到常见问题），代码里有 debug 构建与测试规格，方便后续迭代。

## 快速上手

1. 拿到 `NoteBase.exe`，放到任意目录双击运行（免安装）；
2. 新建分类 → 新建笔记，富文本和代码模式随写随切；
3. 想加密的笔记右键上锁；
4. `Ctrl+S` 随时保存——当然，自动保存也在盯着。
